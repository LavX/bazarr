# Support

Start with the [Bazarr+ guides](https://lavx.github.io/bazarr/guides/) for installation, providers, migration, subtitle processing and integrations.

- For setup questions and community help, join [Discord](https://discord.gg/fpp5JXmB8f).
- For a reproducible bug, use the [bug report form](https://github.com/LavX/bazarr/issues/new?template=bug_report.md).
- For a product suggestion, use the [feature request form](https://github.com/LavX/bazarr/issues/new?template=feature_request.md).
- For a vulnerability, follow [SECURITY.md](SECURITY.md) and report it privately.

Before posting logs, remove API keys, passwords, tokens, media names and filesystem paths you do not want to disclose.
