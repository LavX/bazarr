Guides

Step-by-step setup guides for Bazarr+: install with Docker, add subtitle providers through Provider Hub, connect Jellyfin and VLSub over the External Integration endpoint, translate subtitles with AI, run actions in bulk across your whole library, and migrate from upstream Bazarr without losing your database or config.

Subtitle Processing v2.4

Bulk Operations
