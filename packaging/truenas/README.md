# TrueNAS Apps catalog contribution

Copy `ix-dev/community/bazarr-plus/` into the same path in the [TrueNAS Apps catalog](https://github.com/truenas/apps). The source directory includes the app form, template, static values, and renderer test values. Do not copy this wrapper README into the catalog app directory.

The source was prepared against `truenas/apps` commit `4df7498747aad81b1049135539c65c383e42df95` ([contribution guide](https://github.com/truenas/apps/blob/4df7498747aad81b1049135539c65c383e42df95/CONTRIBUTIONS.md), [existing Bazarr app](https://github.com/truenas/apps/tree/4df7498747aad81b1049135539c65c383e42df95/ix-dev/community/bazarr), [library 2.3.14](https://github.com/truenas/apps/tree/4df7498747aad81b1049135539c65c383e42df95/library/2.3.14)). The vendored `templates/library/base_v2_3_14/` is copied from that official library, whose repository [LICENSE](https://github.com/truenas/apps/blob/4df7498747aad81b1049135539c65c383e42df95/LICENSE) is LGPL-3.0. The official contribution guide requires shipping this generated library with the app. The image is `ghcr.io/lavx/bazarr:2.7.0`; both amd64 and arm64 manifests were present on 2026-09-28. The matching [source tag](https://github.com/LavX/bazarr/releases/tag/v2.7.0) is `9f845dfbb9f3e18e2db7775acd65afa699b5ea3b`.

The [icon](https://lavx.github.io/bazarr/screenshots/logo128.png) and [social preview](https://lavx.github.io/bazarr/screenshots/github-social-preview.png) are live PNGs. TrueNAS may move the icon to its CDN during review; the social preview is available for the contribution description. `item.yaml` is generated by the catalog tooling and is intentionally absent.

Validation on 2026-09-28 against the pinned catalog checkout:

- `./.github/scripts/ci.py --train community --app bazarr-plus --test-file basic-values.yaml --render-only=true` passed and its rendered Compose passed `docker compose config`. It maps host port `30504` to container port `6767`, mounts persistent `/config`, and sets root startup, `PUID=568`, `PGID=568`, read-only root, `/tmp` tmpfs, and only `CHOWN`, `SETUID`, `SETGID` capabilities on the app container.
- The same command with `--test-file media-host-paths.yaml` passed. It adds writable `/movies`, `/tv`, and `/sports` host paths.
- `apps_dev_charts_validate validate --path /workspace` exited 0 in `ghcr.io/truenas/apps_validation:latest` (image digest `sha256:3f38cdaa6ed9c54e5c9c43ec15790aabc0028631dd3f0c28129832a69fd1f30c`). The temporary checkout needed `git add -N ix-dev/community/bazarr-plus` and Docker `GIT_CONFIG_COUNT=1`, `GIT_CONFIG_KEY_0=safe.directory`, `GIT_CONFIG_VALUE_0=/workspace` so the validator could discover the uncommitted app. It did not require a commit.

The [native TrueNAS 25.10.7 validation](native-validation.md) passed installation, image health, web UI, UID/GID drop, writable movie/TV/sports datasets, config persistence across an app restart, and clean uninstall in a disposable appliance. It deployed the rendered Compose as a native TrueNAS custom app with host-path config storage. Catalog ingestion and the default ixVolume lifecycle remain untested.
