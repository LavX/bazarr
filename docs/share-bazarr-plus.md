# Share Bazarr+

Use this kit when introducing Bazarr+ to a community that would benefit from it. Adapt the opening to that community instead of posting the same announcement everywhere.

## One sentence

Bazarr+ is a self-hosted subtitle manager that can search, preview and download subtitles for any film or show with no library connected, or automate Sonarr, Radarr and Sportarr libraries.

## Short post

Bazarr+ now works with no Sonarr or Radarr library at all. Open Discover, search any film or show, preview the available subtitles and download the one you want. If you do run a media stack, it can still automate Sonarr, Radarr and Sportarr, then refresh Plex, Jellyfin, Emby or Silo.

It is self-hosted, ships as a multi-architecture Docker image and sends no telemetry.

## Proof points

- Standalone Discover search with subtitle preview and browser download
- Optional Sonarr, Radarr and Sportarr automation, including multiple instances
- Installable provider plugins, subtitle sync, bilingual output and AI translation
- Native refresh integrations for Plex, Jellyfin, Emby and Silo
- No tracking
